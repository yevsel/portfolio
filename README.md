# Yevoo Justice Selasi — Portfolio

Single-page portfolio site, live at [yevsel.com](https://yevsel.com).

## Stack

Plain HTML + CSS in one file (`index.html`) — no build step. Swiss Grid / museum direction: a strict 12-column grid, one typeface pair (Inter Tight + Inter, loaded from Google Fonts with a Helvetica fallback), hairline rules, generous whitespace, and a single signal red. Smooth in-page anchor scrolling and restrained hover transitions only.

Two small inline scripts add progressive enhancement: a light/dark theme toggle and scroll-reveal animations. No framework, no bundler.

## Structure

- `index.html` — the entire site (markup + styles + inline scripts)
- `videos.json` — latest YouTube uploads, generated by `scripts/sync_youtube.py`
- `scripts/sync_youtube.py` — pulls the channel RSS feed into `videos.json`
- `avatar.jpg` — optimized profile photo used in the hero
- `og-image.png` — 1200×630 Swiss-style social share card
- `favicon.ico`, `favicon-16.png`, `favicon-32.png` — portrait favicon (16/32/48 multi-size `.ico` plus PNGs)
- `apple-touch-icon.png` — 180×180 home-screen icon for iOS
- `profile_picture.png` — original, full-resolution source photo (not deployed)
- `robots.txt`, `sitemap.xml` — search engine crawling/indexing config
- `CNAME` — custom domain config for GitHub Pages (`yevsel.com`)
- `.github/workflows/static.yml` — GitHub Actions workflow that deploys `main` to GitHub Pages on every push, daily at 05:00 UTC, and on demand

## Content

Sections: Summary, YouTube, Core Competencies, Technical Stack, Professional Experience, Selected Systems, Education, Projects, GitHub Activity, Contact. Content is sourced from the résumé (kept locally, gitignored) — update `index.html` directly to reflect résumé changes.

## YouTube videos

YouTube's RSS feed sends no CORS headers, so the browser cannot read it directly. Instead the deploy workflow runs `python3 scripts/sync_youtube.py` before publishing, which writes `videos.json` from the channel feed; the page fetches that same-origin file and renders the cards. Run the script locally to refresh the list when previewing:

```bash
python3 scripts/sync_youtube.py
```

The workflow is scheduled daily, so new uploads appear without a manual push. If the feed is unreachable, the script keeps the previously generated file.

## GitHub activity

The contribution graph and stats are fetched live from the public [github-contributions-api](https://github.com/grubersjoe/github-contributions-api) and rendered in the site's own styling. If the API is unavailable, the section falls back to a link to the GitHub profile.

## Deployment

Push to `main` — GitHub Pages builds and deploys automatically via the Actions workflow. No manual build step required.

## SEO

The page includes meta description/keywords, canonical URL, Open Graph + Twitter Card tags, and JSON-LD `Person` structured data. `sitemap.xml` and `robots.txt` are served from the repo root.
